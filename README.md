# Trăn — Học mỗi ngày, lớn mỗi ngày

Ứng dụng tự học lớp 9–10 trong một file HTML: học bài ngắn, luyện nhiều dạng câu hỏi, ôn cách quãng, thẻ nhớ,
đề thử; nhận vàng để nuôi linh vật Trăn.

**Mở app:** https://vutaitam.github.io/tran-hoc-moi-ngay/
